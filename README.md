## Hardware

- Raspberry Pi Zero WH (with pre-soldered header)
- 3.7" ePaper Display Raw Panel - Red/Yellow/Black/White (416x240)
- Universal ePaper Driver HAT for Raspberry Pi
- Adafruit ANO Rotary Navigation Encoder to I2C Stemma QT Adapter - Pre-Soldered Encoder
- Adafruit Pi Stemma QT Breakout for Raspberry Pi
- STEMMA QT / Qwiic JST-SH 4-pin Cable (100mm)
